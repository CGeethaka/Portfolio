U.S. Trade & Tariff Impact Analysis

Power BI Dashboard — 2024 Economic Analysis

Project Overview

This project analyzes the economic effects of U.S. tariffs introduced in 2024, with a deep focus on trade deficits, tariff responses from trading partners, and product-level price impacts across key industries. The goal was to transform complex multi-source trade data into a clear, interactive narrative for business decision-makers.

Objectives

  • Visualize the scale and direction of U.S. trade deficits by country and region
  • Measure the intensity of applied tariffs and their correlation with price changes
  • Identify the most affected product categories using product-level data
  • Enable dynamic exploration through interactive filters and slicers

Data & Methodology

  • Three integrated datasets: country-level trade data, time-series tariff rates, and product-level price impact data
  • Data cleaning and transformation performed using Power Query inside Power BI
  • DAX measures created: Net Trade Balance, Deficit per Capita, Tariff Intensity %, Price Increase %
  • Relationships built across datasets using country codes and HS product codes

Dashboard Features

  • Interactive map chart showing trade deficit by country with drill-down capability
  • KPI cards displaying headline metrics: total deficit, average tariff rate, top impacted sectors
  • Area charts tracking tariff changes and trade volumes over time (2020–2024)
  • Pie chart breaking down deficit contribution by trading partner group
  • Product impact table with sorting, filtering and conditional formatting
  • Custom slicers for year, country, and product category filtering

Key Insights Delivered

  • Countries with the highest tariff intensity showed measurable consumer price increases within 6 months
  • Electronics and steel were the most heavily impacted product categories
  • Dashboard enabled non-technical stakeholders to explore trade patterns without SQL or Excel

Airline Passenger Satisfaction Analysis

Python Exploratory Data Analysis — 12,981 Records

Project Overview

This project conducts a comprehensive exploratory data analysis (EDA) on airline passenger satisfaction data using Python. By examining 12,981 passenger records, it uncovers the demographic, behavioral, and service-related factors that most strongly influence whether a passenger is satisfied or dissatisfied with their flight experience.

Objectives

  • Understand the overall distribution of satisfaction across the passenger dataset
  • Identify key factors driving dissatisfaction (delays, service quality, seat comfort, etc.)
  • Compare satisfaction rates across gender, age group, customer type and travel class
  • Deliver actionable visual insights to support airline service improvement decisions

Dataset

  • Records: 12,981 passenger entries
  • Features: Gender, age, customer type (loyal/disloyal), travel class, flight distance, departure/arrival delays, and 14 service rating categories
  • Target variable: Passenger satisfaction (Satisfied / Neutral or Dissatisfied)

Methodology & Analysis

  • Data loading, inspection and null-value handling using Pandas
  • Univariate analysis: distribution plots for age, flight distance, ratings
  • Bivariate analysis: satisfaction broken down by gender, travel class, and customer loyalty
  • Delay impact analysis: correlation between departure/arrival delays and satisfaction scores
  • Heatmap of service attribute correlations using Seaborn

Visualizations Created

  • Countplots for satisfaction by gender and customer type
  • Box plots comparing flight distance distributions for satisfied vs dissatisfied groups
  • Bar charts of average service ratings grouped by satisfaction level
  • Scatter plots of delay duration vs satisfaction outcomes
  • Correlation heatmap across all numeric service attributes

Key Findings

  • Business class passengers had significantly higher satisfaction rates than economy class
  • Loyal customers showed higher satisfaction regardless of delay severity
  • Online boarding and inflight WiFi were the most impactful service attributes on satisfaction
  • Arrival delays above 30 minutes showed a marked drop in satisfaction scores

Market Basket Analysis

Association Rule Mining — E-Commerce Retail

Project Overview

This project applies association rule mining to e-commerce transaction data to discover which products are frequently bought together. The insights are used to inform product bundling strategies, cross-selling recommendations, and promotional campaigns for retail businesses.

Objectives

  • Discover frequent itemsets within retail transaction records
  • Generate meaningful association rules using support, confidence, and lift metrics
  • Identify the strongest product affinities to drive bundling and upsell strategies
  • Provide actionable recommendations for marketing and inventory planning

Methodology

  • Transaction data preprocessed and converted into a one-hot encoded basket matrix
  • Apriori Algorithm applied to identify frequent itemsets above a minimum support threshold
  • Association rules generated and ranked by confidence and lift
  • Rules filtered to surface only high-confidence, high-lift product pairs

Key Metrics Used

  • Support: How frequently an itemset appears in all transactions
  • Confidence: Probability that item B is bought given item A is bought
  • Lift: How much more likely items are bought together vs independently — lift > 1 indicates a genuine association

Business Applications

  • Product bundle recommendations on checkout pages
  • Targeted promotional campaigns for co-purchased product pairs
  • Store layout and shelf placement optimization
  • Inventory forecasting based on product affinity patterns

Housing Prices Inferential Analysis

R Language — Statistical Modelling & Regression Analysis

Project Overview

This project performs a comprehensive statistical analysis of the Boston Housing dataset using the R programming language. It explores and quantifies the relationships between neighbourhood characteristics and median house prices using both descriptive statistics and inferential modelling techniques, culminating in multiple linear regression models to predict housing values.

Objectives

  • Identify and measure variables most strongly correlated with median house prices
  • Build and evaluate simple and multiple linear regression models in R
  • Test statistical significance of predictor variables using hypothesis testing
  • Validate model assumptions through diagnostic plots and residual analysis
  • Communicate findings through well-structured data visualisations

Dataset

  • Source: Boston Housing Dataset (Harrison & Rubinfeld, 1978)
  • Records: 506 census tract observations
  • Key features: Crime rate (CRIM), number of rooms (RM), pupil-teacher ratio (PTRATIO), % lower-status population (LSTAT), proximity to employment centres (DIS), and more
  • Target variable: MEDV — Median value of owner-occupied homes ($000s)

Methodology

  • Descriptive statistics: mean, median, variance, skewness for all features
  • Pearson correlation matrix to identify the strongest predictors of MEDV
  • Simple linear regression (SLR): MEDV ~ RM and MEDV ~ LSTAT individually
  • Multiple linear regression (MLR): MEDV ~ RM + LSTAT + PTRATIO + CRIM
  • Hypothesis testing: t-tests for coefficient significance (p-value < 0.05)
  • Model evaluation using R², Adjusted R², and Residual Standard Error (RSE)
  • Regression diagnostics: Residuals vs Fitted, Q-Q plot, Scale-Location, Cook's Distance

Visualisations Created

  • Histograms of all key variables to assess distributions and skewness
  • Scatter plots with regression lines: MEDV vs RM, MEDV vs LSTAT
  • Boxplots to detect outliers across continuous predictors
  • Correlation heatmap using ggplot2 to visualise feature relationships
  • Diagnostic plot suite for residual analysis and model validation

Key Findings

  • RM (average number of rooms) had the strongest positive correlation with house prices (r = 0.70)
  • LSTAT (% lower-status population) was the strongest negative predictor (r = −0.74)
  • The multiple regression model achieved an Adjusted R² of ~0.73, explaining 73% of price variance
  • CRIM and PTRATIO were statistically significant negative predictors (p < 0.001)
  • Residual diagnostics revealed slight heteroscedasticity at higher predicted values, suggesting potential for log transformation in future iterations
